# Городской глашатай — расширение для SillyTavern

Добавляет пункт в меню "волшебной палочки" (значок рядом с полем ввода). По клику
открывается окошко с кнопками: **Слух**, **Газета**, **Розыск**, **Объявление**.
Нажатие отправляет запрос текущей подключённой модели и показывает результат.

## Установка

### Вариант А — по ссылке из самой таверны (рекомендуется)

1. В SillyTavern откройте вкладку Extensions → **Install extension**.
2. Вставьте ссылку на этот репозиторий: `https://github.com/momomeves/-sillynotes`.
3. Подтвердите установку — SillyTavern сам склонирует репозиторий в
   `public/scripts/extensions/third-party/-sillynotes` и включит расширение.
4. Откройте меню "волшебной палочки" рядом с полем ввода сообщения — там появится
   пункт "Городской глашатай".

### Вариант Б — вручную

Скопируйте содержимое репозитория (все файлы, включая `manifest.json`) в
`<папка SillyTavern>/public/scripts/extensions/third-party/<любое-имя>/`
и перезапустите SillyTavern (или обновите страницу). Имя папки может быть любым —
код определяет его сам во время выполнения.

## Как это устроено (если захотите доработать)

- `manifest.json` — метаданные расширения (обязателен для любого расширения ST).
- `index.js` — точка входа. При загрузке страницы добавляет кнопку в
  `#extensionsMenu` (это и есть меню волшебной палочки) и рисует своё модальное
  окно поверх страницы.
- Генерация текста идёт через `getContext().generateRaw({ systemPrompt, prompt })` —
  это "чистый" запрос к текущей LLM без добавления истории чата самим SillyTavern
  (историю при желании подмешиваем сами, см. `buildContextSnippet`).
- Чтобы добавить новый жанр (например, "гороскоп" или "рецепт"), достаточно
  добавить новый ключ в объект `GENRES` в `index.js` — кнопка появится сама.
- Папка расширения может называться как угодно (SillyTavern называет её по имени
  репозитория при установке по ссылке) — `index.js` вычисляет своё реальное
  расположение через `import.meta.url`, поэтому ничего не сломается.

## Важно про версии SillyTavern

Разметка меню волшебной палочки (`#extensionsMenu`, классы `list-group-item`,
`extensionsMenuExtensionButton`) — устоявшийся, но не жёстко документированный
паттерн, которым пользуются многие сторонние расширения. Если после установки
кнопка не появляется, откройте DevTools (F12), найдите элемент, который
раскрывается по клику на палочку, и проверьте его `id` — возможно, в вашей
версии он называется иначе, тогда достаточно поправить один селектор
`$("#extensionsMenu")` в конце `index.js`.
